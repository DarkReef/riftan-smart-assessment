# Riftan Smart Assessment 0.1.3

Самостоятельный релиз из приватного репозитория.

- Подписи свойств оружия берутся из публичного API локализации системы.
- Русские строки переброса используют «Судьбу».
- Сохранены помощник Active Effects, проверка владения, защита от повторного
  расхода очков и исходная сложность переброса.

Для полного перевода свойств используйте Apex Heresy RU 1.5.2 с переводчиком
терминов. Минимальный контракт перебросов: система 1.5.1.

Скачайте архив релиза из приватного репозитория под своим GitHub-аккаунтом
и распакуйте в Data/modules/riftan-smart-assessment. Токены в manifest не добавляйте.

Автоматические тесты пройдены; live multiplayer QA новой сборки не выполнялся.
