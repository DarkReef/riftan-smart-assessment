# Riftan Smart Assessment 0.2.0

- Справка боевых действий перенесена из экспериментального PR системы в самостоятельный модуль. Для неё не требуется новая версия Apex Heresy RU; действующий минимальный контракт системы — 1.5.1.
- F1 открывает/закрывает компактную таблицу: 34 действия Only War, поиск по названиям и условиям, фильтры времени и книги. Клавиша переназначается в настройках управления модуля.
- Кнопка «Боевые действия» добавлена в раздел документации боковой вкладки настроек, рядом с поддержкой и руководством, и в главное меню Esc. Доступна игрокам и ведущему; повторный вызов выводит одно окно вперёд.
- Полное, частичное/полудействие, свободное, реакция и длительные затраты различаются. Противоречия Выжидания и Прыжка в русском OW видны со страницами. DH2/BC/RT/DW не получают непроверенные правила OW.
- Сохранены помощник Active Effects, поиск полей и перебросы за Судьбу. Добавлены макросы api.openCombatActionReference() и api.toggleCombatActionReference() в API модуля.
- Архив включает шаблон справки, стили и документацию. Перед публикацией проверяются версия тега, совпадение манифестов и наличие файлов/импортов.

Проверки: 29 автоматических тестов успешно на локальной установке Foundry 14.368,
включая настоящие классы обработки клавиатуры. В CI без лицензированного клиента
этот интеграционный тест пропускается, остальные 28 выполняются.
Браузерный стенд проверяет F1, поиск, фильтры, переназначение, кнопки обоих меню и
повторное открытие; оболочка ApplicationV2 заменена тестовой. Полный игровой мир
и многопользовательская сессия пока не проверены.

Установка и обновление через Foundry:
https://github.com/DarkReef/riftan-smart-assessment/releases/latest/download/module.json
