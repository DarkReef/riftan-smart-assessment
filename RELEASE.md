# Smart Assessment 0.3.0 — релиз для тестирования в Foundry

Подтверждаемый урон Only War внутри Smart Assessment. Ядро системы владеет расчётом,
правами и журналом; модуль предоставляет карточку, выбор одной цели, решение GM,
кнопки подтверждения и закрытую детализацию. Требуется отдельный патч Apex Heresy
1.5.6 с damage API v1. F1-справка и прежние AE/Fate функции сохранены.

Поддержаны Pen, Unnatural +X, Felling, True Grit, отдельные попадания, ordinary/critical
счётчики и RF как отдельный эффект. Непроверенные свойства/защиты остановлены до
автоматического применения. Критические таблицы целиком и полный Undo не заявлены.
Ручной итог после всех защит/True Grit сохраняется с причиной.

Фактические проверки и инструкции: docs/combat-damage-v0.1.md. Браузерные сквозные
сценарии используют подменённый document/network host. Живой multiplayer QA не
выполнен. Релиз поставляется отдельным ZIP; main не изменён. Автоматические обновления используют release manifest.
