# Riftan Smart Assessment 0.4.0

Переброс за Судьбу поддерживает единую боевую карточку Apex Heresy RU 1.7.0. Результат, история «было → стало» и выбранная цитата сохраняются в исходной карточке. Модуль больше не ждёт отдельного сообщения результата и не возвращает уже потраченную Судьбу из-за такого ожидания. Обычные карточки продолжают создавать отдельный результат.

Перед расходом Судьбы модуль проверяет состояние связанных боевых действий. Переброс недоступен после применения урона или состояния подавления, при выполняющейся операции либо необходимости её проверки мастером. Отмена броска до сохранения результата возвращает очко; ошибка косметической истории после сохранённого результата его не возвращает.

Для пакета `apex-heresy-ru` требуется **система 1.7.0+**. Прежний пакет Apex с ID `dark-heresy` сохраняет минимум 1.5.6 и прежнее поведение карточек. Система Vendare не является совместимой заменой. Система и модуль устанавливаются отдельно.

Проверки: 38 автоматических тестов прошли, одна проверка диспетчера клавиатуры требует установленного Foundry и пропущена. Новые проверки выполняют реальные методы модуля и службу Судьбы с синтетическими документами: обновление исходной карточки, прежний путь создания сообщения, отмена, чужой ID запроса, запрет после применения последствий и сбой истории. Живой многопользовательский прогон ещё требуется.
