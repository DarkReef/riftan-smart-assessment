# Riftan Smart Assessment 0.3.1

- Поддержка отдельного пакета Apex Heresy RU `apex-heresy-ru` 1.6.0+; прежний пакет `dark-heresy` 1.5.6+ с damage API v1 остаётся совместимым.
- Перебросы Судьбы, карточки урона, помощник эффектов и справка действий принимают оба ID. Сохранённые флаги чата читаются без проверки прежнего ID как установленного пакета; данные и CSS сохранены.
- Для нового ID указан манифест DarkReef; ссылка прежнего ID закреплена на релизе системы 1.5.6. Vendare не поддерживается.

Проверки: 32 автоматических теста пройдены; одна проверка диспетчера клавиатуры требует установленного Foundry и пропущена. Живая многопользовательская проверка после смены ID системы ещё требуется. Ограничения расчёта урона сохранены: [описание](docs/combat-damage-v0.1.md).

Установка: https://github.com/DarkReef/riftan-smart-assessment/releases/latest/download/module.json
